# City of Shadows 🌆🌑

> Open Packs · Unlock Characters · Explore

## What is PackWorld?
A dark open world game where you complete levels to earn packs, and open packs to unlock characters and items.

## Current Features
- ✅ Login / Sign Up page
- ✅ Open World (coming soon in development)

## Coming Soon
- 🔒 Special Character Unlock Levels
- 🔒 PVP Mode

## How to Run
Just open `index.html` in your browser — no setup needed!

## Deployment
This project is deployed via [Railway](https://railway.app).
